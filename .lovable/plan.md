# AVTOQISM Premium UI Prototype

## Scope
Build only four polished, navigable screens with static prototype data and lightweight presentation interactions. No backend, database, authentication, APIs, payments, or production business logic.

## Visual direction
- Light, editorial automotive interface for Home, Garage, and Product Detail
- Cinematic dark treatment for the Social Feed
- Strong display typography, disciplined whitespace, crisp dividers, restrained shadows, and limited corner rounding
- Original high-quality Chevrolet Cobalt and automotive-product imagery created for the prototype
- Uzbek interface copy and realistic so‘m pricing throughout

## Screens
1. **Home (`/`)** — personalized Chevrolet Cobalt header, For Your Car, Trending, Recommended Videos, Nearby Sellers, and Categories.
2. **Garage (`/garage`)** — prominent vehicle portrait, specifications, ownership details, compatible products, and Add Vehicle action.
3. **Product Detail (`/product`)** — large image gallery, title, price, rating, verified seller, stock, delivery, prominent compatibility confirmation, and purchase CTAs.
4. **Social Feed (`/feed`)** — immersive 9:16 automotive video-style presentation, minimal content overlay, seller, caption, product, price, compatibility, social actions, and “Mahsulotni ko‘rish”.

## Interaction and polish
- Shared navigation connects all four screens.
- Subtle transitions, image/gallery selection, saved/liked states, and responsive layouts provide prototype realism without complex functionality.
- Verify desktop and mobile presentation, navigation, legibility, and metadata for every screen.

## Technical details
- TanStack Start routes with React and Tailwind CSS v4.
- Semantic OKLCH design tokens in the global stylesheet; no hardcoded component colors.
- Local generated image assets and iconography; no remote placeholders.
