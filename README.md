AVTOQISM is a premium automotive social commerce platform for Uzbekistan.

Core idea:

Garage → Discover → Compatibility → Buy

Design direction:

- premium automotive technology

- minimal

- sophisticated

- strong typography

- excellent whitespace

- editorial composition

- restrained shadows

- subtle borders

- refined micro-interactions

- high quality automotive imagery

- light mode as primary

- cinematic dark mode for Feed

Avoid:

- generic SaaS UI

- generic ecommerce template

- excessive cards

- excessive rounded corners

- excessive gradients

- glassmorphism

- neon

- racing clichés

- generic AI-generated layouts

The interface must feel deliberately designed by a senior product designer.
